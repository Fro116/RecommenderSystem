# Installing Dependencies
* [cuda](https://developer.nvidia.com/cuda-downloads)
* [cwebp](https://developers.google.com/speed/webp/download)
* [docker](https://docs.docker.com/get-started/get-docker)
* [gcloud](https://cloud.google.com/sdk/docs/install)
* [julia](https://julialang.org/downloads/)
  * Run `julia requirements.jl` to install dependencies in the project `../../juliaenv`
* [miller](https://github.com/johnkerl/miller)
* [python](https://www.python.org/downloads/)
  * Run `pip install -r requirements.txt` to install dependencies in the environment `../../venv`
* [rclone](https://rclone.org/install/)
* [vastai](https://cloud.vast.ai/cli/)
* [waifu2x](https://github.com/nagadomi/nunif/blob/master/README.md#install)
  * Install at `../../nunif`
* [zstd](https://github.com/facebook/zstd)
* Place all secrets (cloud credentials, etc.) in `../secrets`
